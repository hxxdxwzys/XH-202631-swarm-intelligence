# MaAS: Multi-agent Architecture Search via Agentic Supernet

> [!info] 元信息
> - **ArXiv**: `2502.04180`
> - **作者 / 年份**: Guibin Zhang et al. (NUS/同济/NTU/上海AI Lab/USTC) / 2025
> - **主题分类**: [[topology-communication]]
> - **本地文本**: [2502.04180.txt](file:///../_pdf_text/2502.04180.txt)

## 一句话总结
放弃"一个万能多 agent 系统"，转而优化"agentic supernet"（agent 架构的概率连续分布），按查询从 supernet 采样出查询依赖的多 agent 系统，实现量身资源分配，六基准上仅用 6–45% 推理成本且性能更高。

## 问题与动机
自动设计 agentic workflow 多寻求"一个静态复杂万能系统"，无法按每个查询的难度/领域动态分配推理资源，简单查询也用重系统，浪费。

## 核心方法
- **Agentic supernet**：agent 架构的概率连续分布。
- 按查询从 supernet 采样查询依赖的多 agent 系统，量身分配 LLM 调用/工具调用/token。
- 构件：CoT/Reflexion/ReAct/Debate/I/O/Web search/Evaluator-optimizer/Exit 等。

## 关键贡献
- 把 NAS 思想引入多 agent 架构搜索，按查询动态选架构与资源。
- 大幅降本同时提质，跨数据集/跨 LLM backbone 迁移性好。

## 实验与数据
- 六基准：仅 6–45% 推理成本，性能 +0.54–16.89%；跨数据集与 backbone 迁移性强。

## 局限与不足
- supernet 训练成本；采样策略依赖训练；长程任务与端边云未涉及；与记忆容错未结合。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
MaAS 是赛题"动态异构拓扑 + 资源自适应调度"的旗舰方法：按查询难度动态采样架构与资源——同时命中拓扑与效率。其"简单查询用轻系统、复杂查询用重系统"正是赛题低熵与效率的理想形态。可与 [[2410.11782 G-Designer]]、[[2506.02951 Adaptive Graph Pruning]]、[[2410.10762 AFlow]] 形成动态架构搜索方法簇。
