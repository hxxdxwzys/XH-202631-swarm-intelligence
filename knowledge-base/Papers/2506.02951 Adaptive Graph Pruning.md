# Adaptive Graph Pruning (AGP) for Multi-Agent Communication

> [!info] 元信息
> - **ArXiv**: `2506.02951`
> - **作者 / 年份**: Boyi Li, Zhonghan Zhao et al. (浙大-UIUC联合学院/浙大) / 2025
> - **主题分类**: [[topology-communication]]
> - **本地文本**: [2506.02951.txt](file:///../_pdf_text/2506.02951.txt)

## 一句话总结
提出 AGP：联合优化 agent 数量（hard pruning）与通信拓扑（soft pruning），两阶段训练先学各 agent 数下的最优完全图与位置掩码、再在最大完全图内联合硬软剪枝，按任务动态配置 agent 数与拓扑，六基准 SOTA 且 token 降 90%+。

## 问题与动机
既有方法 agent 数固定或拓扑静态、需人工预定义，难同时按任务复杂度动态调 agent 数与拓扑；仅优化边权（soft）仍受限于固定 agent 池，可能漏掉关键 agent。

## 核心方法
- **Hard pruning**：选 agent 数量；**Soft pruning**：优化通信边/拓扑。
- 两阶段：Stage I 独立训练不同 agent 数的 soft-pruning 网络，得各 agent 数最优完全图与位置掩码；Stage II 在最大完全图内联合优化 hard+soft。
- 用图自编码器(GAE)做 soft-pruning。
- 关键洞察：最有用 agent 有时反直觉，人工设计有极限。

## 关键贡献
- 首个联合动态调 agent 数 + 拓扑的任务自适应框架。
- 六基准 SOTA（+2.58–9.84%），token 降 90%+，训练高效（约 10 步超基线）。

## 实验与数据
- 六基准 SOTA、跨多 LLM 架构泛化；token 降 90%+；约 10 训练步超基线。

## 局限与不足
- 需训练 GAE；hard/soft 联合优化复杂；长程任务与端边云未涉及；与记忆容错未结合。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
AGP 是赛题"动态异构拓扑 + 低熵通信"的强方法：同时动态调 agent 数与拓扑、token 大降——逐条命中。其"hard pruning 选角色 + soft pruning 选路由"可作赛题动态组队与路由的核心算法。与 [[2410.11782 G-Designer]]、[[2410.02506 AgentPrune]]、[[2502.04180 MaAS Agentic Supernet]] 形成动态拓扑+剪枝方法簇。
