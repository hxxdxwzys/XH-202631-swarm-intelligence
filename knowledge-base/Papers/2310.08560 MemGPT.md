# MemGPT: Towards LLMs as Operating Systems

> [!info] 元信息
> - **ArXiv**: `2310.08560`
> - **作者 / 年份**: Charles Packer et al. (UC Berkeley) / 2023
> - **主题分类**: [[memory-longcontext]]
> - **本地文本**: [2310.08560.txt](file:///../_pdf_text/2310.08560.txt)

## 一句话总结
借鉴操作系统的虚拟内存分页，为 LLM 设计分层"虚拟上下文管理"：在有限上下文窗口与外部存储间智能分页换入换出，营造无限上下文错觉，支持超长文档分析与多会话长期对话。

## 问题与动机
LLM 受限于固定上下文窗口，长对话/长文档场景严重受限；直接扩上下文带来二次方计算开销，且长上下文模型利用效率低（lost in the middle）。

## 核心方法
- **虚拟上下文管理**：把上下文窗口视作受限"主存"，设计类似 OS 的分层存储。
- 用**函数调用**让 agent 读写外部存储、修改自身上下文、决定何时响应用户——在上下文窗口与外部存储间"分页"。
- 通过函数调用管理控制流（上下文管理/响应生成/用户交互）。
- 评估文档分析与多会话聊天两域。

## 关键贡献
- 提出 OS 启发的虚拟上下文范式，使固定上下文模型处理超长上下文。
- 把记忆管理显式化为 agent 可自主调用的函数（自管理记忆）。

## 实验与数据
- 可分析远超上下文窗口的大文档；多会话聊天中可记忆、反思、长期演化。

## 局限与不足
- 依赖 LLM 自主调用记忆函数的可靠性；分页策略可能不当；函数调用开销；多 agent 协作未原生支持。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
MemGPT 是赛题"分布式记忆架构"与"上下文压缩唤醒"的核心范本：分层存储 + 分页换入换出 = 不依赖长窗口的长程记忆。其"agent 自主管理记忆（函数调用）"可直接迁移到赛题记忆层(#3)与执行引擎(#4)的检查点机制。是赛题长程记忆支柱的必读基线。
