# The Landscape of Emerging AI Agent Architectures (Survey)

> [!info] 元信息
> - **ArXiv**: `2404.11584`
> - **作者 / 年份**: Tula Masterman, Mason Sawtell, Sandi Besen, Alex Chao (IBM/MS) / 2024
> - **主题分类**: [[survey]]
> - **本地文本**: [2404.11584.txt](file:///../_pdf_text/2404.11584.txt)

## 一句话总结
综述单 agent 与多 agent 架构的近期实现，聚焦推理/规划/工具调用，提炼架构选型主题、领导力影响、通信风格与"规划-执行-反思"关键阶段，为 agent 设计提供选型指南。

## 问题与动机
agent 实现快速涌现（AutoGPT/BabyAGI 等），社区争论单 agent vs 多 agent；需系统梳理设计模式、分歧与对目标达成的影响，指导选型。

## 核心方法
- 单 agent vs 多 agent 架构概览，识别关键模式与设计分歧。
- 主题：架构选型、领导力(leadership)对 agent 系统的影响、通信风格、规划/执行/反思关键阶段。
- 采用 brain-perception-action 的 agent 定义。
- 评注各架构能力与局限。

## 关键贡献
- 提炼 agent 架构选型的实操指南（何时单/多 agent、领导力、通信风格）。
- 明确"规划-执行-反思"为鲁棒 agent 系统的关键阶段。

## 实验与数据
综述性，无单一实验；提供架构对比与选型建议。

## 局限与不足
- 偏工程选型，对动态图路由、低熵通信、端边云等前沿覆盖浅；架构快速演进易过时。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
本文是赛题架构选型(#1)与底座决策的实操指南：单/多 agent 取舍、领导力（层级编排）、通信风格、规划-执行-反思阶段——直接对应赛题"组织架构与协作机制"打分点。建议团队据此决策"自研底座 vs 借鉴框架"，并明确规划-执行-反思三阶段在系统中的落地。
