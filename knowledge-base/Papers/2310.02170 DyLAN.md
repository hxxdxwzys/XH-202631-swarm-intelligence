# DyLAN: Dynamic LLM-Powered Agent Network

> [!info] 元信息
> - **ArXiv**: `2310.02170`
> - **作者 / 年份**: Zijun Liu et al. (清华/Georgia Tech/AIR/Stanford) / 2024
> - **主题分类**: [[topology-communication]]
> - **本地文本**: [2310.02170.txt](file:///../_pdf_text/2310.02170.txt)

## 一句话总结
针对"固定 agent 数 + 静态通信结构"的局限，提出 DyLAN：用时序前馈网络(T-FFN)建模多 agent 协作，先以"Agent Importance Score"做任务导向的团队优选，再让选定 agent 动态协作求解。

## 问题与动机
既有通信结构（debate/self-collaboration）成员固定、结构不变；agent 多为人工预设或 LLM 生成却不验证协作过程，导致静态团队或无原则重建。

## 核心方法
两阶段：
1. **Team Optimization**：基于无监督的 Agent Importance Score（预试验中的贡献度）从候选中选出最相关 agent；
2. **Task Solving**：选定 agent 依查询动态协作。
- 用**时序前馈网络(T-FFN)** 表达：每步通信为网络层，节点为该步参与的 agent，边为通信——天然容纳动态团队。

## 关键贡献
- 首个显式做"任务导向动态 agent 选择 + 动态通信结构"的框架，直击赛题痛点。
- 提出无监督的 Agent Importance Score 作为选择度量。

## 实验与数据
- 代码生成/决策/一般推理/算术推理上超越强基线，成本适中；MMLU 部分科目团队优选提升准确率最高 25%。

## 局限与不足
- T-FFN 仍是层状结构，非任意稀疏图；选择基于预试验，开销与稳定性有限；未涉及低熵通信协议与长程记忆。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
DyLAN 是赛题"动态异构拓扑"最直接的先驱之一：团队随任务动态优选、通信结构随查询变化，而非静态全连接。其 Agent Importance Score 可作为动态路由的打分依据（谁该参与）。建议在其基础上升级为任意稀疏图路由 + 结构化低熵消息协议。
