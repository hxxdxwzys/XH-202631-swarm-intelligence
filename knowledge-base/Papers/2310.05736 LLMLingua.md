# LLMLingua: Prompt Compression for Accelerated Inference

> [!info] 元信息
> - **ArXiv**: `2310.05736`
> - **作者 / 年份**: Huiqiang Jiang et al. (Microsoft) / 2023
> - **主题分类**: [[memory-longcontext]]
> - **本地文本**: [2310.05736.txt](file:///../_pdf_text/2310.05736.txt)

## 一句话总结
提出 coarse-to-fine 的提示压缩法：用预算控制器在高压缩比下保语义完整，用 token 级迭代压缩建模条件依赖，并用指令调优对齐小模型与目标 LLM 分布，实现最高 20x 压缩几乎无损。

## 问题与动机
CoT/ICL/RAG 让提示动辄上万 token，带来高计算成本与延迟；模型侧量化压缩不适用于 API-only LLM。自然语言本身有冗余，可压缩。

## 核心方法
- 动机：低困惑度(PPL) token 对熵增益贡献小，删除影响小。
- **预算控制器**：对指令/示范/问题动态分配不同压缩比，做示范级粗压缩保语义。
- **token 级迭代压缩**：考虑 token 间条件依赖，细粒度保留关键信息。
- **分布对齐**：指令调优使压缩用小模型与目标 LLM 分布一致。

## 关键贡献
- 提出 coarse-to-fine 提示压缩，兼顾高压缩比与语义完整。
- 20x 压缩几乎无损；首个在推理与 ICL 域评估高效 LLM 的工作。

## 实验与数据
- GSM8K/BBH/ShareGPT/Arxiv-March23 四域 SoTA；最高 20x 压缩性能损失小。

## 局限与不足
- 压缩需额外小模型前向；对极长上下文仍偏全局压缩、未充分问题感知（见 LongLLMLingua）；可能丢细节。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
LLMLingua 是赛题"上下文压缩唤醒"与"低熵通信"的直接工具：压缩 agent 间消息与上下文以降 token、抑制冗余。其"低 PPL token 可删"思想可用于执行引擎(#4)的消息瘦身。但需配合问题感知（见 [[2310.06839 LongLLMLingua]]）避免丢关键信息。
