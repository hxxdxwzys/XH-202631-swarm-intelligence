# AgentPrune: Economical Communication for Multi-Agent

> [!info] 元信息
> - **ArXiv**: `2410.02506`
> - **作者 / 年份**: Guibin Zhang et al. (同济/上海AI Lab/CUHK/UNC) / 2024
> - **主题分类**: [[topology-communication]]
> - **本地文本**: [2410.02506.txt](file:///../_pdf_text/2410.02506.txt)

## 一句话总结
首次正式定义多 agent 通信"冗余"问题，在时空消息传递图上做一次性剪枝，去除冗余甚至恶意消息，以极低成本与大幅 token 削减达到 SOTA 拓扑的同等性能，并抵御 agent 对抗攻击。

## 问题与动机
精心设计的通信拓扑带来集体智能，但引入巨额 token 开销与经济成本，阻碍大规模部署；且存在冗余甚至恶意消息。

## 核心方法
- 形式化定义多 agent 通信冗余问题。
- **时空消息传递图**上做一次性剪枝（spatial-temporal），产出 token 经济且高性能的拓扑。
- 区分 intra-dialogue（一轮内多 agent 交互）与 inter-dialogue（轮间传递）通信。
- 可无缝集成主流多 agent 框架。

## 关键贡献
- 首个形式化并解决多 agent 通信冗余的框架，直击赛题"低熵通信"。
- 降 token 28.1–72.8%、抵御对抗攻击 +3.5–10.8%。

## 实验与数据
- 六基准：与 SOTA 拓扑相当性能，成本仅 $5.6 vs $43.7；token 降 28.1–72.8%；抗两类对抗攻击 +3.5–10.8%。

## 局限与不足
- 一次性剪枝，非在线动态；剪枝判据偏启发式；未结合长程记忆与端边云；与动态图生成尚未统一。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
AgentPrune 几乎逐字命中赛题"抑制通信冗余与噪声级联""显著降低交互信息熵"——是低熵通信支柱的核心方法。其"时空消息图剪枝 + 抗对抗"同时服务低熵与鲁棒容错。执行引擎(#4)可直接在消息出口做剪枝/结构化过滤。建议与 [[2410.11782 G-Designer]]、[[2506.02951 Adaptive Graph Pruning]] 形成"动态生成+剪枝"低熵通信组合。
