# Mem0: Scalable Long-Term Memory for AI Agents

> [!info] 元信息
> - **ArXiv**: `2504.19413`
> - **作者 / 年份**: Prateek Chhikara, Dev Khant et al. (Mem0) / 2025
> - **主题分类**: [[memory-longcontext]]
> - **本地文本**: [2504.19413.txt](file:///../_pdf_text/2504.19413.txt)

## 一句话总结
面向生产的可扩展长期记忆架构：动态从对话中抽取、整合、检索显著信息，并提供图记忆变体捕获关系结构；在 LOCOMO 上跨四类问题超越所有记忆基线，p95 延迟降 91%、token 成本省 90%+。

## 问题与动机
LLM 固定上下文窗口使长多会话对话难以保持一致；RAG 是无状态补丁，缺生命周期控制与持久表征；需生产级可扩展长期记忆。

## 核心方法
- 动态抽取、整合、检索对话中的显著信息。
- **图记忆变体**：用图表示捕获会话元素间复杂关系。
- 在 LOCOMO 上对比六类基线（记忆增强系统、RAG、全上下文、开源/闭源记忆方案、记忆管理平台）。

## 关键贡献
- 生产就绪的可扩展长期记忆，含图记忆增强。
- 同时提升准确率与大幅降延迟/成本。

## 实验与数据
- LLM-as-Judge 比 OpenAI 相对提升 26%；图记忆比基础 Mem0 高约 2%；p95 延迟降 91%、token 省 90%+。

## 局限与不足
- 面向对话记忆，非任务推理记忆；图记忆构建维护成本；与多 agent 动态拓扑未结合。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
Mem0 是赛题"分布式记忆架构"与"上下文压缩唤醒"的生产级参照：动态抽取整合+图记忆+大幅降 token，正中长程记忆与效率两项。其图记忆可捕获任务实体关系，与 [[2310.08560 MemGPT]] 的分层分页互补。记忆层(#3)可直接借鉴其抽取-整合-检索管线。
