# OpenHands (OpenDevin): Open Platform for AI Software Developers

> [!info] 元信息
> - **ArXiv**: `2407.16741`
> - **作者 / 年份**: Xingyao Wang et al. (UIUC/CMU/All Hands AI 等) / 2025
> - **主题分类**: [[agent-framework]]
> - **本地文本**: [2407.16741.txt](file:///../_pdf_text/2407.16741.txt)

## 一句话总结
社区驱动的开源 agent 平台（前 OpenDevin）：以事件流架构连接 UI/agent/环境，提供 Docker 沙箱运行时（shell+浏览器+IPython）、类人软件开发接口、多 agent 委派与评测框架，跨 15 项挑战任务评估。

## 问题与动机
agent 能力增长使其开发与评测变难；需一个让 agent 像人类开发者那样通过写代码、用命令行、浏览网页来影响世界的开源平台。

## 核心方法
- **事件流架构**：UI、agent、环境通过事件流交互，强大灵活。
- **运行时**：Docker 沙箱 OS，含 bash shell、web 浏览器、IPython server。
- **类人接口**：创建/修改复杂软件、沙箱内执行任意代码、浏览网站。
- **多 agent 委派**：多个专门 agent 协作。
- **评测框架**：跨 SE(SWE-bench)/Web(WebArena) 等 15 任务。

## 关键贡献
- 提供完整可用的开源通用 agent 平台（事件流+沙箱+多 agent+评测）。
- 基于 CodeAct 的强通用 agent + agent hub（10+ 实现）。

## 实验与数据
- 跨 15 项挑战任务评测；MIT 许可，188+ 贡献者、2.1K+ 贡献。

## 局限与不足
- 多 agent 委派偏静态；通信非图化动态拓扑；长程记忆与低熵协议未原生；沙箱运维重。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
OpenHands 是赛题执行引擎(#4 工具调用/部署/沙箱)与可运行系统的强参照：Docker 沙箱执行、事件流架构、CodeAct（代码即动作）皆可复用。其沙箱隔离直接服务鲁棒容错（节点失效/异常注入可在沙箱内安全演示）。可作为赛题底座候选之一，但需叠加动态拓扑与记忆容错。
