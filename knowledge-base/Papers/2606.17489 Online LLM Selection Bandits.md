# Online LLM Selection via Constrained Bandits

> [!info] 元信息
> - **ArXiv**: `2606.17489`
> - **作者 / 年份**: Yin Huang, Qingsong Liu, Jie Xu (UF/UMass) / 2026
> - **主题分类**: [[inference-serving]]
> - **本地文本**: [2606.17489.txt](file:///../_pdf_text/2606.17489.txt)

## 一句话总结
把边-云推理系统中"为每个任务选合适 LLM"建模为带硬(packing)/软(covering)约束与时变需求的受限随机 bandit 问题，用置信界估计+需求预测平衡奖励最大化与长期约束满足，给出次线性 regret 与约束违反保证。

## 问题与动机
LLM 在精度/延迟/成本上异构且随机未知，任务需求时变；静态选择失效。真实部署有硬预算（货币上限）与软 SLA（延迟保证）两类约束，在线决策难。

## 核心方法
- 受限随机 bandit：顺序选模型，同时满足 packing(硬，累计成本不超预算) 与 covering(软，累计服务达下限) 约束，适应时变需求。
- 仅部分反馈，无奖励/成本/延迟分布先验。
- 算法用置信界估计 + 需求预测，平衡探索利用与长期约束。
- 理论：相对全信息离线基准的次线性 regret 与次线性 covering 约束违反。

## 关键贡献
- 把在线 LLM 选择形式化为带硬软约束的 bandit，给出理论保证。
- 融合需求预测应对时变负载。

## 实验与数据
- 合成负载验证有效性与鲁棒性（动态、资源受限环境）。

## 局限与不足
- 合成负载为主；面向模型级选择，非 agent 任务级动态拓扑；与记忆/容错未结合。
