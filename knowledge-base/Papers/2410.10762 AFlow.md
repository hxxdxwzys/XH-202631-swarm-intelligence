# AFlow: Automating Agentic Workflow Generation

> [!info] 元信息
> - **ArXiv**: `2410.10762`
> - **作者 / 年份**: Jiayi Zhang et al. (DeepWisdom/HKUST-GZ/RUC/南大/复旦/KAUST) / 2025
> - **主题分类**: [[topology-communication]]
> - **本地文本**: [2410.10762.txt](file:///../_pdf_text/2410.10762.txt)

## 一句话总结
把 agentic workflow 优化建模为"代码表示的 workflow 上的搜索问题"（LLM 调用节点+边），用 MCTS 迭代改进（代码修改+树结构经验+执行反馈）自动生成 workflow，平均超 SOTA 5.7%，并让小模型以 4.55% 成本超 GPT-4o。

## 问题与动机
agentic workflow 需大量人工设计，限制可扩展与可迁移；既有自动化方法仍依赖初始人工设置，未实现全自动化有效生成。

## 核心方法
- workflow 建模为相互连接的 LLM 调用节点图（代码表示），边定义逻辑/依赖/流。
- **MCTS** 在 workflow 代码空间搜索：代码修改 + 树结构经验 + 执行反馈迭代精炼。
- 全自动，无需初始人工 workflow。

## 关键贡献
- 把 workflow 生成统一为图上 MCTS 搜索，实现全自动。
- 让小模型以极低成本超 GPT-4o，证明 workflow 优化可弥补模型差距。

## 实验与数据
- 六基准平均 +5.7% over SOTA；小模型以 4.55% GPT-4o 成本在特定任务超 GPT-4o。

## 局限与不足
- MCTS 搜索成本；workflow 偏单 agent 流而非多 agent 动态协作；长程任务与端边云未涉及。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
AFlow 的"workflow=图、用 MCTS 自动生成与优化拓扑"是赛题"全局动态任务编排"与"自适应网络拓扑流转"的直接实现路径：拓扑随任务自动生成而非预设。其"小模型+优 workflow 超 GPT-4o"对赛题效率与多模型兼容有强启示。可与 [[2402.16823 GPTSwarm]]（边优化）、[[2310.04406 LATS Language Agent Tree Search]]（MCTS）形成动态编排方法簇。
