# G-Designer: Architecting Multi-agent Topologies via GNN

> [!info] 元信息
> - **ArXiv**: `2410.11782`
> - **作者 / 年份**: Guibin Zhang et al. (CUHK/同济/Emory/USTC/NUS/UNC) / 2025
> - **主题分类**: [[topology-communication]]
> - **本地文本**: [2410.11782.txt](file:///../_pdf_text/2410.11782.txt)

## 一句话总结
用变分图自编码器编码 agent 节点与任务虚拟节点，解码出任务自适应的高性能通信拓扑；按任务难度定制拓扑，HumanEval 上 token 降 95.33%，并抗对抗攻击（仅 0.3% 性能 drop）。

## 问题与动机
拓扑繁多（chain/tree/star/complete/random/optimizable），实践者难以为具体任务选最优拓扑——既要避免不必要 token 开销又要保高质量。同一数据集内不同难度子集最优拓扑不同。

## 核心方法
- 把多 agent 系统建模为网络，用**变分图自编码器**编码节点(agent)+任务虚拟节点，解码任务自适应拓扑。
- 提出 **MACP（多 agent 通信协议）** 标准化拓扑设计指导。
- 拓扑按任务难度自适应：简单任务用经济拓扑（如 chain），难任务用复杂拓扑。

## 关键贡献
- 首个用 GNN 自动设计任务自适应多 agent 通信拓扑的框架。
- 同时实现高性能、token 经济、对抗鲁棒。

## 实验与数据
- 六基准：MMLU 84.50%、HumanEval pass@1 89.90%；HumanEval token 降 95.33%；抗对抗仅 0.3% drop。

## 局限与不足
- 拓扑生成离线/半在线；依赖训练数据；长程任务与端边云未涉及；与记忆容错未结合。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
G-Designer 是赛题"动态异构拓扑 + 低熵通信"的旗舰参照：任务自适应生成拓扑、按难度经济选型、token 大降——逐条命中赛题要求。其 MACP 协议与 GNN 解码器可作为赛题动态路由算法的核心候选。抗对抗能力也服务鲁棒容错。是赛题拓扑-通信支柱的必读基线，与 [[2402.16823 GPTSwarm]]、[[2410.02506 AgentPrune]]、[[2310.02170 DyLAN]] 形成方法簇。
