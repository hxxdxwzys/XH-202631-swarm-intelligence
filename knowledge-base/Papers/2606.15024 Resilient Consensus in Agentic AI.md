# Resilient Consensus in Agentic AI

> [!info] 元信息
> - **ArXiv**: `2606.15024`
> - **作者 / 年份**: Sribalaji C. Anand, George J. Pappas (KTH/Penn) / 2026
> - **主题分类**: [[safety-robustness]]
> - **本地文本**: [2606.15024.txt](file:///../_pdf_text/2606.15024.txt)

## 一句话总结
把 LLM agent 达成共识建模为拜占庭共识博弈，发现纯 prompt 的 LLM agent 在经典理论保证可收敛的设置下仍会失败，而用经典弹性共识滤波器（MSR）包裹 agent 可恢复共识，收益取决于拓扑本身提供的鲁棒性。

## 问题与动机
LLM agent 越来越多部署于需协调达成共同决策的 MAS；当 agent 故障或对抗时，共识变非平凡。经典弹性共识理论面向确定性 agent，能否迁移到可能对抗的 LLM agent？

## 核心方法
- 把 LLM 一致性建模为 **Byzantine consensus game**。
- 在完全图与一般通信图上做受控实验。
- 用经典 **MSR-type 弹性共识滤波器**（全局/局部）包裹 prompt agent。
- 经典条件：完全图 N≥3B+1；一般图需 N≥3B+1 且 B<κ/2（κ 为连通度）。

## 关键贡献
- 首次把经典弹性共识理论与 LLM agent 联系，揭示 prompt 策略在安全区内仍失败。
- 证明经典 MSR 滤波器可恢复 LLM agent 共识，滤波收益依赖拓扑鲁棒性。

## 实验与数据
- prompt agent 在 N≥3B+1 内仍共识失败；MSR 滤波恢复完全图共识、改善一般图；跨温度与 horizon 鲁棒。

## 局限与不足
- 偏理论与小规模实验；面向共识任务，非通用长程任务；与记忆/端边云未结合。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
本文是赛题鲁棒容错支柱的理论利器：拜占庭共识 + MSR 滤波为"节点失效/对抗 agent"提供形式化容错框架。其"拓扑连通度决定容错上限"直接指导赛题动态拓扑设计——拓扑不仅要低熵，还要保足够连通度以容 B 个失效。可与 [[2606.10662 DeLM Decentralized MAS]] 的去中心化、[[2410.02506 AgentPrune]] 的抗对抗结合，构建赛题容错通信底座。
