# TheAgentCompany: Benchmarking Agents on Real-World Tasks

> [!info] 元信息
> - **ArXiv**: `2412.14161`
> - **作者 / 年份**: Frank F. Xu et al. (CMU/Duke) / 2024
> - **主题分类**: [[benchmark]]
> - **本地文本**: [2412.14161.txt](file:///../_pdf_text/2412.14161.txt)

## 一句话总结
构建自包含的模拟软件公司环境（内部网站+数据+模拟同事），175 个真实职业任务（工程/PM/财务/HR），agent 须浏览 Web、写代码、跑程序、与同事沟通；最强 agent 仅自主完成 30%，长程任务仍超能力。

## 问题与动机
缺乏客观基准衡量 agent 加速/自主完成真实工作的能力；商业与政策 implications 重大，需看清 agent 能做与不能做的边界。

## 核心方法
- 模拟小型软件公司：内部网站、数据、模拟同事（测 agent 沟通）。
- 175 任务跨 SDE/PM/财务/HR 等真实职业场景。
- 自托管可复现；checkpoint + 执行式评测，部分正确给部分分。

## 关键贡献
- 首个系统化"数字工人"长程职业任务基准，含沟通与部分评分。
- 揭示长程任务仍是 agent 短板（30% 自主完成）。

## 实验与数据
- 12 个 LLM backbone（闭源+开源）；最强 30% 自主完成；长程任务难。

## 局限与不足
- 单 agent 评测；模拟公司范围有限；未涉及多智能体动态拓扑；环境部署重。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
TheAgentCompany 是赛题"数字劳动力"场景与评测(#5/#6)的高价值参照：真实职业任务、长程、执行式+部分评分。其 30% 完成率与"长程任务超能力"的结论直接论证赛题鲁棒容错与长程记忆的必要性。可作为赛题多任务演示与评测的任务来源。
