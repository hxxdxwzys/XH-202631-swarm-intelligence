# WorkArena: Web Agents for Knowledge Work Tasks

> [!info] 元信息
> - **ArXiv**: `2403.07718`
> - **作者 / 年份**: Alexandre Drouin et al. (ServiceNow/Mila/Polytechnique) / 2024
> - **主题分类**: [[benchmark]]
> - **本地文本**: [2403.07718.txt](file:///../_pdf_text/2403.07718.txt)

## 一句话总结
面向企业知识工作的 Web agent 基准：基于 ServiceNow 平台的 33 个任务、19912 实例，覆盖知识工作者日常操作；配套 BrowserGym 环境提供丰富动作与多模态观测，揭示当前 agent 与全自动化仍有显著差距。

## 问题与动机
既有 Web agent 任务多为玩具页面或少数真实站点，未触及企业软件——后者功能优先、UX 复杂、学习曲线长，正是 agent 提效与可及性的高价值场景。

## 核心方法
- **WorkArena**：基于 ServiceNow（财富 500 中 85% 使用）的 33 任务、19912 实例，覆盖企业常见交互。
- **BrowserGym**：Web agent 设计与评测环境，丰富动作集 + 多模态观测（HTML/可访问性树/截图）。
- 兼容 WebArena 等既有基准。

## 关键贡献
- 首个系统化企业知识工作 Web agent 基准，贴近真实劳动力场景。
- BrowserGym 统一 Web agent 评测环境。

## 实验与数据
- 当前 agent 有潜力但距全自动化差距大；开源与闭源 LLM 性能差异显著。

## 局限与不足
- 单 agent Web 评测；任务偏中短程；未涉及多智能体协作与动态拓扑。
