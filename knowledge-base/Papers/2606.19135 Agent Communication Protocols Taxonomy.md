# A Technical Taxonomy of LLM Agent Communication Protocols

> [!info] 元信息
> - **ArXiv**: `2606.19135`
> - **作者 / 年份**: Linus Sander et al. (TUM) / 2026
> - **主题分类**: [[survey]]
> - **本地文本**: [2606.19135.txt](file:///../_pdf_text/2606.19135.txt)

## 一句话总结
对 9 个活跃维护的开源 LLM agent 通信协议做技术分类：五维度（counterparty/payload/交互状态/发现机制/schema 灵活度）揭示 recurring 模式——agent 间协议普遍混合 payload + 会话状态持久化、多预设 schema、去中心化发现罕见；短期趋向统一 agent 间与 agent-context 通信，长期走向联邦分层协议栈。

## 问题与动机
协议景观碎片化带来互操作性挑战；缺乏统一标准使异构 agent 难以动态发现与协作；硬编码通信管道是反模式，需协议标准化。

## 核心方法
- 迭代 taxonomy 法：定义目的/元特征/终止条件，5 轮迭代（3 经验到概念、2 概念到经验）。
- 分析 9 个有采用的开源协议。
- 五维度：counterparty、payload、interaction state、discovery mechanism、schema flexibility。

## 关键贡献
- 建立 agent 通信协议的技术 taxonomy，填补协议系统分类空白。
- 揭示协议收敛趋势与长期联邦分层栈方向，指出隐私/策略执行等开放缺口。

## 实验与数据
综述性，无单一实验；9 协议分类与模式归纳。

## 局限与不足
- 9 个协议样本有限；偏描述性；与动态拓扑生成、端边云着墨少。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
本文是赛题"结构化消息协议"与"低熵通信"的直接工程参照：五维度（尤其 payload 与 schema flexibility）可作为赛题消息信封设计的检查清单。其"混合 payload + 会话状态持久化""去中心化发现罕见"等发现指导赛题协议取舍。与 [[2502.14321 Communication-Centric Survey]] 并列为赛题通信子系统设计的核心综述。
