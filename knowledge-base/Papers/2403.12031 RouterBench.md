# RouterBench: A Benchmark for Multi-LLM Routing

> [!info] 元信息
> - **ArXiv**: `2403.12031`
> - **作者 / 年份**: Qitian Jason Hu et al. (Martian/UCB/UCSD) / 2024
> - **主题分类**: [[benchmark]]
> - **本地文本**: [2403.12031.txt](file:///../_pdf_text/2403.12031.txt)

## 一句话总结
首个面向多 LLM 路由系统的综合基准：含 405k+ 来自代表 LLM 的推理结果，按推理美元成本与性能评估路由机制，并提出路由理论框架与多种路由策略对比。

## 问题与动机
无单一 LLM 能在性能-成本上最优解所有任务；路由系统按输入选最优模型以平衡性能与成本。但缺乏标准基准评估路由机制，阻碍进展。

## 核心方法
- **RouterBench**：整合 8 数据集 × 11 模型，预生成响应与质量指标，免推理即可训练/测试路由器。
- 提出路由理论框架：按 WTP(willingness to pay) 等度量评估。
- 对比多种路由策略，揭示其泛化能力与局限。

## 关键贡献
- 首个系统化 LLM 路由基准与理论框架，把路由评估标准化。
- 证明即使简单路由在某些领域也表现突出，但复杂任务泛化难。

## 实验与数据
- 405k+ 推理结果；多路由策略对比，揭示潜力与局限。

## 局限与不足
- 面向模型级路由（黑盒 API），非 agent/任务级动态拓扑；未涉及多 agent 协作与长程；成本模型偏 API 计价。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
RouterBench 是赛题"按子任务动态选模型/位置"的评测参照：把"为每个输入选最优模型"的思路扩展到"为每个子任务选最优 agent/算力位置"。其成本-性能权衡框架可直接用于赛题 token/时间效率打分的设计。模型级路由可与赛题 agent 级动态拓扑互补。
