# LATS: Language Agent Tree Search

> [!info] 元信息
> - **ArXiv**: `2310.04406`
> - **作者 / 年份**: Andy Zhou et al. (UIUC/Lapis Labs) / 2024
> - **主题分类**: [[reasoning]]
> - **本地文本**: [2310.04406.txt](file:///../_pdf_text/2310.04406.txt)

## 一句话总结
把 ReAct 扩展为在"推理+动作"组合空间上的搜索：用 MCTS 统一推理、动作与规划，配 LM 价值函数与自我反思，借助环境外部反馈实现审慎决策。

## 问题与动机
ReAct 等方法具反射性但缺乏前瞻与多路径考虑；搜索式 LM 工作又缺外部反馈。需要统一推理/动作/规划、并能利用环境反馈的框架。

## 核心方法
- **LATS**：把 ReAct 扩展为对推理-动作组合空间的搜索。
- 用 **MCTS** 适配语言 agent：节点/提示存储并检索外部反馈，搜索算法把反馈纳入价值赋分的启发式。
- LM 驱动的**价值函数** + **自我反思**促进探索；以语言为各组件接口，免训练适配。

## 关键贡献
- 首个统一推理/动作/规划的 LM agent 框架，把 MCTS 引入语言 agent。
- 用环境反馈 + LM 价值函数 + 反思实现审慎、自适应决策。

## 实验与数据
- 编程(HumanEval+GPT-4) pass@1 92.7% SoTA；WebShop(GPT-3.5) 75.9，可比梯度微调；跨编程/交互QA/Web/数学验证。

## 局限与不足
- MCTS 搜索成本高（多次模拟+价值评估）；依赖 LM 价值函数质量；树规模控制难；token 开销大。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
LATS 的"MCTS 搜索 + 自我反思 + 环境反馈"是鲁棒容错与规划层的高阶范本：走错可回溯、可反思重选。对赛题高风险决策节点可借鉴，但需严控成本（仅关键分叉启用），否则长程任务 token 爆炸。其"统一推理-动作-规划"也与赛题"深度协同推理"契合。
