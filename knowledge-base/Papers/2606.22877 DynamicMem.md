# DynamicMem: Long-Horizon Memory Benchmark

> [!info] 元信息
> - **ArXiv**: `2606.22877`
> - **作者 / 年份**: Wenya Xie et al. (Minnesota/UNC Charlotte/JHU/Cisco/Adobe) / 2026
> - **主题分类**: [[benchmark]]
> - **本地文本**: [2606.22877.txt](file:///../_pdf_text/2606.22877.txt)

## 一句话总结
合成 15 个月用户行为轨迹（人均 2.2M token、1772 事件、跨 16 应用）评测长程记忆：用户画像（属性/习惯/偏好）多时间尺度演化、由季节与生活事件驱动、证据分散于多应用小动作中；揭示 profile 重建随历史退化、>93% 失败源于检索而非生成。

## 问题与动机
既有记忆评测用短简化交互，缺真实长程行为三特性：画像异构（多时间尺度）、变化由外部上下文驱动、证据分散隐含需推断。

## 核心方法
- 15 个月用户一致轨迹，均 2.2M token、1772 grounded 事件，跨 16 应用。
- 画像含属性(离散变)/习惯(中期可逆)/偏好(长期漂移)，由季节与生活事件驱动。
- 画像不显式给出，须从分散行为信号推断。
- 五个季度 checkpoint 评测；两类任务：状态补全、个性化服务。

## 关键贡献
- 首个真实长程（15 月）多应用记忆基准，含漂移与隐含证据。
- 关键诊断：>93% 失败源于检索（记忆）而非生成；profile 重建随历史退化而服务任务准确率持平。

## 实验与数据
- 5 代表系统：profile 重建随历史退化；无系统既能保留真事实又能替换变化事实；>93% 失败在检索。

## 局限与不足
- 合成数据；面向个人助理画像，非任务推理长程；单 agent 评测。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
DynamicMem 是赛题长程记忆支柱的高价值评测参照：15 个月、2.2M token、多应用漂移——正是赛题"超长程上下文连续性""抗遗忘"的极端测试。其">93% 失败在检索"结论直接指导赛题记忆层(#3)：重点不在写而在"唤醒/检索"质量。可与 [[2606.24775 Agent-Native Memory System]]、[[2504.19413 Mem0]] 形成长程记忆评测簇。
