# GPTSwarm: Language Agents as Optimizable Graphs

> [!info] 元信息
> - **ArXiv**: `2402.16823`
> - **作者 / 年份**: Mingchen Zhuge et al. (KAUST/IDSIA) / 2024
> - **主题分类**: [[topology-communication]]
> - **本地文本**: [2402.16823.txt](file:///../_pdf_text/2402.16823.txt)

## 一句话总结
把 LLM agent 系统统一描述为计算图（节点=操作如 LLM 推理/工具，边=信息流），agent 是子图、群体是复合图；并用图优化器自动改节点 prompt（节点优化）与改图连通性（边优化）来自动改进编排。

## 问题与动机
各种 prompt 工程（CoT/ReAct/ToT/Reflexion/GoT）与多 agent 框架代码库割裂、需大量人工定义 prompt 方案与工作流；缺乏统一表示与自动改进结构的方法。

## 核心方法
- **图表示**：节点为操作（LLM 推理/工具），边为信息流；agent=节点图，swarm=复合图；CoT/ToT/Self-Consistency 等均可表为图。
- **协作 = 图间信息流；编排 = 复合图的边连接**。
- **图优化器**：① 节点优化（依反馈改 prompt）；② 边优化（改邻接矩阵/连通性，改进编排）。
- 边连通性可在线自改进或跨任务迁移。

## 关键贡献
- 用可优化计算图统一异质 prompt 工程与多 agent 编排。
- 证明自动优化图连通性（拓扑）可超越人工设计的 suboptimal agent 组织。

## 实验与数据
- 概念验证：自动重组 ToT/Reflexion 等已有技术，优化边后性能提升。

## 局限与不足
- 图优化成本与搜索空间；优化目标偏任务正确率，未显式优化通信熵/token；大规模长程任务验证有限。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
GPTSwarm 是赛题"基于图结构的动态路由"与"协同推理微基座"的核心理论参照：把 agent 编排统一为可优化图，拓扑随任务自动生成与改进——正中赛题要害。可直接作为赛题动态拓扑的算法底座，并扩展为以"低熵/低 token"为优化目标的边优化。
