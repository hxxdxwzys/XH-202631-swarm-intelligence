# MemOS: A Memory Operating System for AI

> - **ArXiv**: `2507.03724`

## 一句话总结
把记忆作为可管理的系统资源，提出 MemOS：统一表征、调度、演化明文/激活级/参数级三类记忆，以 MemCube（封装内容+溯源+版本等元数据）为基本单元，可组合、迁移、融合，支撑持续学习与个性化。

## 问题与动机
LLM 缺乏记忆管理系统，阻碍长上下文推理、持续个性化与知识一致性；RAG 是无状态补丁，缺生命周期控制；知识跨时间与上下文分布，需管理异构、跨时间尺度的知识。

## 核心方法
- **MemOS**：把记忆作为系统资源，统一明文/激活/参数级记忆的表征、调度、演化。
- **MemCube**：基本单元，封装记忆内容 + 溯源、版本等元数据；可组合、迁移、融合。
- 分层记忆层级：工作记忆、长期存储、冷归档，按 recency/访问频次/重要性调度。
- 跨用户/agent 共享需 scoping、权限控制、可迁移可复用表征。

## 关键贡献
- 提出记忆操作系统范式，统一三类异构记忆与生命周期管理。
- MemCube 抽象使记忆可组合/迁移/融合，桥接检索与参数学习。

## 实验与数据
- PreFEval/PersonaMem/LongMemEval/LoCoMo 全基准 SOTA，超 MIRIX/Mem0/Zep 等。

## 局限与不足
- 系统复杂度高；激活/参数级记忆工程化难；面向对话/个性化，任务推理长程验证有限；多 agent 协作未深入。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
MemOS 是赛题"分布式记忆架构"与"记忆保持"的系统级范式：把记忆作为 OS 资源统一管理、分层调度、可迁移可复用——正中"不依赖单一模型长窗口""关键信息长链不丢失"。其 MemCube 可作为赛题记忆层(#3)与执行引擎(#4)检查点的统一抽象。是赛题长程记忆支柱的前沿必读。
