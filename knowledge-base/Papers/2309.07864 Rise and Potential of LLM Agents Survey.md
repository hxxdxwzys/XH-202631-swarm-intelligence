# The Rise and Potential of LLM-Based Agents: A Survey

> [!info] 元信息
> - **ArXiv**: `2309.07864`
> - **作者 / 年份**: Zhiheng Xi et al. (Fudan NLP) / 2023
> - **主题分类**: [[survey]]
> - **本地文本**: [2309.07864.txt](file:///../_pdf_text/2309.07864.txt)

## 一句话总结
从哲学起源到 AI 发展梳理 agent 概念，提出 LLM-agent 通用框架（大脑-感知-动作），并系统综述单 agent、多 agent、人机协作及 agent 社会的应用与开放问题。

## 问题与动机
社区缺乏一个通用强大模型作为设计可适应多样场景 agent 的起点；LLM 被视为 AGI 火种，需系统梳理以 LLM 为基础的 agent 研究全貌。

## 核心方法
- **通用框架**：Brain（自然语言交互/知识/记忆/推理规划/迁移泛化）+ Perception（文/视/听/其他）+ Action（文/工具/具身）。
- 梳理应用：单 agent（任务/创新/生命周期部署）、多 agent（合作互补/对抗促进）、人机协作（指令-执行/平等伙伴）。
- 探讨 agent 社会：行为与人格、社会现象、对人类社会的启示。

## 关键贡献
- 提出 brain-perception-action 通用框架，成为 LLM agent 研究的经典组织主线。
- 系统连接哲学、AI、社会模拟，提供开放问题清单与论文库。

## 实验与数据
综述性论文，无单一实验；提供分类体系与文献索引。

## 局限与不足
- 框架偏概念性；对动态拓扑、低熵通信、端边云等赛题核心议题覆盖较浅（写作时点较早）。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
