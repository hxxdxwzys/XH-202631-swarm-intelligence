# Agentic Memory (AgeMem): Unified LTM & STM Management

> [!info] 元信息
> - **ArXiv**: `2601.01885`
> - **作者 / 年份**: Yi Yu et al. (武大/阿里巴巴) / 2026
> - **主题分类**: [[memory-longcontext]]
> - **本地文本**: [2601.01885.txt](file:///../_pdf_text/2601.01885.txt)

## 一句话总结
把长期(LTM)与短期(STM)记忆管理统一进 agent 策略：记忆操作暴露为工具动作，agent 自主决定何时存/取/更新/摘要/丢弃；用三阶段渐进 RL + step-wise GRPO 训练，五项长程基准上稳定超越记忆增强基线。

## 问题与动机
LTM 与 STM 多被分开处理、靠启发式或辅助控制器，限制适应性与端到端优化；分离优化后 ad hoc 组合导致记忆构建碎片化、性能次优。

## 核心方法
- **AgeMem**：LTM/STM 管理直接集成进 agent 策略，记忆操作即工具动作（store/retrieve/update/summarize/discard）。
- 三阶段渐进 RL 训练统一行为；设计 **step-wise GRPO** 应对记忆操作带来的稀疏、不连续奖励。
- 统一构建而非独立组合。

## 关键贡献
- 首个把 LTM+STM 统一进 agent 策略并端到端 RL 训练的框架。
- step-wise GRPO 解决记忆操作的稀疏奖励问题。

## 实验与数据
- 五项长程基准跨多 backbone 超越记忆增强基线：任务性能↑、LTM 质量↑、上下文用量更高效。

## 局限与不足
- 需 RL 训练，成本高；依赖奖励设计；多 agent 协作与动态拓扑未涉及。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
AgeMem 是赛题长程记忆支柱的前沿方法：记忆操作工具化 + agent 自主管理 + 端到端 RL——实现"关键信息长链不丢失、不漂移"且上下文高效（低熵）。其"存/取/更新/摘要/丢弃"操作集可直接纳入执行引擎(#4)与记忆层(#3)的工具接口。与 [[2310.08560 MemGPT]]、[[2504.19413 Mem0]]、[[2507.03724 MemOS]] 形成长程记忆方法簇。
