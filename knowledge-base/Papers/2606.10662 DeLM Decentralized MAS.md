# DeLM: Decentralized MAS with Shared Context

> [!info] 元信息
> - **ArXiv**: `2606.10662`
> - **作者 / 年份**: Yuzhen Mao, Azalia Mirhoseini (Stanford) / 2026
> - **主题分类**: [[topology-communication]]
> - **本地文本**: [2606.10662.txt](file:///../_pdf_text/2606.10662.txt)

## 一句话总结
提出 DeLM 去中心化 MAS：并行 agent + 共享已验证上下文 + 任务队列，agent 异步认领子任务、读取累计进展、写回紧凑已验证更新，以共享上下文为通信基底，避免中心编排瓶颈，在 SWE-bench Verified 与 LongBench-v2 上性能领先且成本减半。

## 问题与动机
现有 MAS 多靠中心化编排：主 agent 分派、收集、合并，随子任务增多成为通信与整合瓶颈，且主 agent 在路由中可能稀释/遗漏/扭曲有用细节。

## 核心方法
- **去中心化协调**：并行 agent + 共享已验证上下文 + 任务队列。
- agent 异步认领子任务、读累计进展、做局部推理、写回紧凑已验证更新。
- 共享上下文作通用通信基底，agent 互建对方已验证进展，无需经中心控制器。

## 关键贡献
- 提出去中心化 + 共享已验证上下文范式，打破中心编排瓶颈。
- 同时提升 SE test-time scaling 与长上下文推理，成本降约 50%。

## 实验与数据
- SWE-bench Verified：Avg@1/Pass@2/Pass@4 最佳，最高 +10.5pp，成本约 −50%；LongBench-v2 Multi-Doc QA 四模型家族最高均准确率，最高 +5.7pp。

## 局限与不足
- 共享上下文一致性/并发控制复杂；依赖已验证写入机制；与动态拓扑生成、端边云未结合。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
DeLM 的"共享已验证上下文 + 任务队列 + 去中心化"高度契合赛题：共享上下文既是长程记忆基底又是低熵通信载体（只写紧凑已验证更新），去中心化避免单点瓶颈与失效。可作为赛题编排与记忆-通信一体化架构的参考。其"写回紧凑已验证更新"正是低熵通信的范本。
