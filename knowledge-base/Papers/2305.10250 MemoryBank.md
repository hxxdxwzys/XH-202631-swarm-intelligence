# MemoryBank: Enhancing LLMs with Long-Term Memory

> [!info] 元信息
> - **ArXiv**: `2305.10250`
> - **作者 / 年份**: Wanjun Zhong et al. (Sun Yat-sen/HIT/KTH) / 2023
> - **主题分类**: [[memory-longcontext]]
> - **本地文本**: [2305.10250.txt](file:///../_pdf_text/2305.10250.txt)

## 一句话总结
为 LLM 设计长期记忆机制：可召唤相关记忆、持续更新、随时间按艾宾浩斯遗忘曲线选择性遗忘与强化，从而在长期陪伴场景中理解并适应用户个性。

## 问题与动机
LLM 缺乏长期记忆，在需要持续交互的场景（个人陪伴、心理咨询、秘书）中无法维持上下文连贯、无法记住用户历史与偏好。

## 核心方法
- **MemoryBank**：记忆存储 + 检索 + 更新机制 + 对过往事件/用户个性的摘要能力。
- **遗忘曲线启发**：依时间流逝与记忆相对重要性，动态遗忘与强化——模拟人类选择性记忆。
- 兼容闭源(ChatGPT)与开源(ChatGLM/BELLE)模型。
- 落地为 SiliconFriend 陪伴 chatbot，并用 38k 心理对话数据微调以增强共情。

## 关键贡献
- 把"遗忘"作为记忆管理一等机制引入 LLM，缓解无限记忆膨胀。
- 长期陪伴场景下展示人格理解与跨会话记忆召回。

## 实验与数据
- 定性（真实用户对话）+ 定量（ChatGPT 模拟多用户长期对话）评估，展示记忆召回与人格适应能力。无标准长程基准对比。

## 局限与不足
- 面向陪伴对话，非长程任务推理；遗忘曲线参数需调；缺乏与任务成功率挂钩的评测；多 agent 协作未涉及。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
"按重要性+时间动态遗忘/强化"是长程记忆支柱的关键技术——千步任务中不可能全量保留，必须有选择性地压缩与遗忘以防膨胀。可与 [[2304.03442 Generative Agents]] 的反思综合结合：遗忘低价值细节、保留高层抽象。但需从对话场景迁移到任务推理场景。
