# DistServe: Disaggregating Prefill and Decoding

> [!info] 元信息
> - **ArXiv**: `2401.09670`
> - **作者 / 年份**: Yinmin Zhong et al. (北大/StepFun/UCSD) / 2024
> - **主题分类**: [[inference-serving]]
> - **本地文本**: [2401.09670.txt](file:///../_pdf_text/2401.09670.txt)

## 一句话总结
把 LLM 服务的 prefill 与 decoding 分配到不同 GPU，消除两相干扰，按应用 TTFT/TPOT 需求为各相协同优化资源与并行策略，并依集群带宽放置两相以最小化解耦通信，显著提升单 GPU goodput。

## 问题与动机
现有系统同机混合 prefill 与 decoding 并跨请求批处理，导致 prefill-decoding 干扰、资源分配耦合；在严格延迟要求下只能优先一相或过度配置算力。

## 核心方法
- **解耦**：prefill 与 decoding 分到不同 GPU，消除干扰。
- **协同优化**：按应用 TTFT(prefill 首 token 时延) 与 TPOT(decoding 每 token 时延) 需求，为各相定制资源分配与并行策略。
- **带宽感知放置**：依集群带宽放置两相，最小化解耦带来的 KV 状态通信。
- 优化目标：单 GPU goodput（满足 SLO 的最大请求率）。

## 关键贡献
- 系统化解耦 prefill/decoding，定义 goodput 为服务优化目标。
- 证明按相专用资源 + 带宽感知放置可大幅提升 SLO 内服务能力。

## 实验与数据
- 比 SOTA 可多服务 7.4x 请求或收紧 12.6x SLO，>90% 请求满足延迟约束。

## 局限与不足
- 面向云端服务集群；需高带宽互联传 KV；对端侧与多 agent 调度未涉及；解耦增加运维复杂度。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
