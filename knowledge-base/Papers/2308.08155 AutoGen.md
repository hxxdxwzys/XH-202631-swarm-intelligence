# AutoGen: Multi-Agent Conversation Framework

> [!info] 元信息
> - **ArXiv**: `2308.08155`
> - **作者 / 年份**: Qingyun Wu et al. (Microsoft Research/Penn State/UW) / 2023
> - **主题分类**: [[agent-framework]]
> - **本地文本**: [2308.08155.txt](file:///../_pdf_text/2308.08155.txt)

## 一句话总结
提出通用多 agent 对话框架：agent 可对话、可定制、可由 LLM/人/工具或其组合驱动，支持灵活对话模式（顺序/层级/人在回路），用自然语言或代码编程编排。

## 问题与动机
单 agent 难应对复杂任务，多 agent 协作可鼓励发散思维、提升事实性与推理、提供校验。但缺乏一个兼具通用抽象与灵活实现的框架来支持跨域、不同复杂度的多 agent 应用。

## 核心方法
- **Conversable agent**：通用可对话 agent，后端可为 LLM/人/工具/组合，可配置不同角色（写码/执行/校验/人在回路）。
- **灵活对话模式**：支持单/多轮、不同人参与模式、静态与动态对话；可用自然语言或代码编程编排。
- 统一接口容纳多种对话模式。

## 关键贡献
- 提出可对话、可定制 agent 的通用抽象，成为最流行的多 agent 框架之一。
- 支持人在回路与灵活拓扑（含层级对话），降低多 agent 应用门槛。

## 实验与数据
- 在数学、编码、QA、运筹、在线决策、娱乐等多域示例应用上验证有效性。

## 局限与不足
- 对话拓扑多为开发者手工编排，非任务语义动态生成；通信偏自然语言（高熵）；缺乏原生长程记忆与容错机制；规模化长程任务易 token 爆炸。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
AutoGen 是赛题可选的底座候选之一（但其"套用框架"会被打分惩罚，需深度重构）。其 conversable agent 抽象与灵活对话模式可作为执行引擎(#4)的 agent 接口参考；但必须把人工编排拓扑升级为动态稀疏图、把自然语言通信升级为结构化低熵协议，并补足记忆与容错。
