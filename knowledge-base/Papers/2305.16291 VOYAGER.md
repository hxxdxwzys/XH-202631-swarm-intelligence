# VOYAGER: An Open-Ended Embodied Agent with LLMs

> [!info] 元信息
> - **ArXiv**: `2305.16291`
> - **作者 / 年份**: Guanzhi Wang et al. (NVIDIA/Caltech/UT Austin/Stanford) / 2023
> - **主题分类**: [[agent-framework]]
> - **本地文本**: [2305.16291.txt](file:///../_pdf_text/2305.16291.txt)

## 一句话总结
首个 LLM 驱动的开放式终身学习 agent：在 Minecraft 中持续探索、积累可执行代码技能库、用环境反馈+执行错误+自我验证迭代改写程序，无需任何参数微调。

## 问题与动机
现有 LLM agent 不是终身学习者，无法跨长时间跨度渐进地获取、积累、迁移技能，存在灾难性遗忘。

## 核心方法
三大模块：
1. **自动课程**：依探索进度与状态生成合适难度的下一任务（新颖性搜索）。
2. **技能库**：以可执行代码存储成功技能，可检索复用，技能可组合、抗遗忘。
3. **迭代提示机制**：用环境反馈、执行错误、自我验证迭代改写程序（code as action）。
通过黑盒 GPT-4 提示，无需微调。

## 关键贡献
- 终身学习 agent 范式：技能库 + 课程 + 迭代修正，能力随时间复合增长。
- "code as action"使动作可时间扩展、可组合、可解释。

## 实验与数据
- 比 prior SOTA 多获 3.3 倍独特物品、行进距离 2.3 倍、解锁科技树快 15.3 倍；技能可迁移到新世界。

## 局限与不足
- 限定 Minecraft 环境；技能库检索与增长管理未深入；依赖 GPT-4；非多 agent 协作；无标准长程任务基准。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
VOYAGER 的"技能库（code）+ 迭代改写（执行错误→自我验证→修正）"高度契合赛题：技能库是长程记忆的程序性记忆形态，可跨任务复用抗遗忘；迭代修正直接服务鲁棒容错支柱。执行引擎(#4)可把"成功工具调用序列沉淀为可复用 skill"作为记忆策略，并把执行错误反馈纳入重试。
