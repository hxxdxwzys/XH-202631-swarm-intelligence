# LLM-based Multi-Agents: A Survey of Progress and Challenges

> [!info] 元信息
> - **ArXiv**: `2402.01680`
> - **作者 / 年份**: Taicheng Guo et al. (Notre Dame/KAUST/SUSTech/UMass) / 2024
> - **主题分类**: [[survey]]
> - **本地文本**: [2402.01680.txt](file:///../_pdf_text/2402.01680.txt)

## 一句话总结
系统综述 LLM 多智能体系统：覆盖其模拟的领域与环境、agent 剖析(profiling)与通信方式、能力增长机制，并梳理常用数据集/基准与挑战。

## 问题与动机
单 LLM agent 已有进展，多 agent 借集体智能与专业化能力求解更复杂问题与社会模拟，但早期工作彼此独立，缺乏系统综述与未来挑战梳理。

## 核心方法
- 综述维度：① 多 agent 模拟的领域与环境；② agent 如何被 profiling；③ agent 间如何通信；④ 能力增长机制；⑤ 数据集/基准。
- 区分"问题求解"与"世界模拟"两大应用取向。
- 维护开源论文库持续更新。

## 关键贡献
- 为 LLM 多 agent 领域建立系统蓝图与术语（profiling、通信、能力增长）。
- 梳理挑战与基准，为后续研究导航。

## 实验与数据
综述性，无单一实验；提供分类体系与论文计数趋势。

## 局限与不足
- 写作时点较早，对动态拓扑、低熵通信、端边云等赛题核心议题覆盖浅；偏描述性。
