# AgentScope: Flexible yet Robust Multi-Agent Platform

> [!info] 元信息
> - **ArXiv**: `2402.14034`
> - **作者 / 年份**: Dawei Gao et al. (Alibaba) / 2024
> - **主题分类**: [[agent-framework]]
> - **本地文本**: [2402.14034.txt](file:///../_pdf_text/2402.14034.txt)

## 一句话总结
以消息交换为核心通信机制的开发者级多 agent 平台，强调鲁棒性：内置/可定制容错、actor 化分布式框架（本地↔分布式无缝切换、自动并行）、多模态与工具/外部知识系统级支持。

## 问题与动机
多 agent 开发比单 agent 复杂：需管理多模型/agent、SOP 或动态工作流、多样通信模式；且 LLM 幻觉与工具不确定性会在多 agent 中级联放大——"aberrations are tinderboxes"。

## 核心方法
- **消息交换**为核心通信机制；丰富语法工具、内置 agent、服务函数、演示与监控界面、零代码工作站、自动 prompt 调优。
- **容错机制**：内置 + 可定制，自主检测处理意外响应，防止级联。
- **actor 化分布式框架**：本地与分布式部署易切换，自动并行优化。
- 系统级支持多模态数据、工具、外部知识。

## 关键贡献
- 把"鲁棒性/容错"作为一等公民纳入多 agent 平台——罕见且贴合赛题。
- actor 化使本地原型到分布式部署平滑迁移。

## 实验与数据
偏平台/系统贡献；展示开发便捷性、容错与分布式能力。

## 局限与不足
- 通信仍以消息交换为主、非图化动态拓扑；容错机制偏工程启发式；长程记忆与低熵协议未深入。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
AgentScope 是赛题执行引擎(#4)与部署的强参照：其"容错机制防级联"几乎是为赛题鲁棒容错支柱写的，其 actor 化分布式框架契合端边云部署与节点失效处理。可借鉴其容错与 actor 模型，但需把消息通信升级为动态稀疏图 + 结构化低熵协议。
