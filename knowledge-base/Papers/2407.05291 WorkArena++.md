# WorkArena++: Compositional Knowledge Work Tasks

> [!info] 元信息
> - **ArXiv**: `2407.05291`
> - **作者 / 年份**: Leo Boisvert et al. (ServiceNow/Mila/Polytechnique) / 2024
> - **主题分类**: [[benchmark]]
> - **本地文本**: [2407.05291.txt](file:///../_pdf_text/2407.05291.txt)

## 一句话总结
把 WorkArena 从 33 个原子任务扩展到 682 个复合任务，要求 web agent 具备规划、问题求解、逻辑/算术推理、检索与上下文理解，并提供可生成数千条 ground-truth 轨迹的机制供微调。

## 问题与动机
WorkArena 任务偏原子（填表、菜单导航），未考察规划与推理；企业知识工作中真正有价值的是复合工作流，agent 在此能力上仍欠探索。

## 核心方法
- 682 个基于 ServiceNow 的复合任务，模拟知识工作者真实工作流（如补货低库存物品）。
- 评估规划/问题求解/逻辑算术推理/检索/上下文理解。
- 提供机制自动生成数千条 ground-truth 观察/动作轨迹供微调。

## 关键贡献
- 首个要求 web agent 复合规划与推理能力的企业基准。
- 提供大规模轨迹生成机制，支撑模型微调。

## 实验与数据
- 跨 SOTA LLM/VLM 与人类评测，揭示模型作为工作助手的多重挑战。

## 局限与不足
- 单 agent Web 评测；任务仍偏中程；未涉及多智能体协作与动态拓扑。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
WorkArena++ 的"复合工作流需规划+推理+记忆"正契合赛题长程任务特征，是赛题"数字劳动力"场景与评测(#5/#6)的高价值参照。其轨迹生成机制可用于构建赛题高质量多智能体数据集（打分项 b）。可与 WorkArena/WebArena 形成 Web 评测簇。
