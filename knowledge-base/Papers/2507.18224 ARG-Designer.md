# ARG-Designer: Autoregressive Topology Generation

> [!info] 元信息
> - **ArXiv**: `2507.18224`
> - **作者 / 年份**: Shiyuan Li et al. (Griffith/Squirrel AI/PolyU) / 2025
> - **主题分类**: [[topology-communication]]
> - **本地文本**: [2507.18224.txt](file:///../_pdf_text/2507.18224.txt)

## 一句话总结
把 MAS 拓扑设计重构为"条件自回归图生成"：从零开始，依自然语言查询顺序动态决定 agent 数量、从可扩展角色池选角色、建立最优通信链，摆脱"模板图修改"范式，六基准 SOTA 且 token 更省、可扩展性更强。

## 问题与动机
既有图学习方法走"模板图修改"范式——从预设 agent 集与硬编码结构出发做边重权/剪枝，存在冗余组成（无关 agent/边残留）与扩展性差两大限制。

## 核心方法
- **条件自回归图生成**：系统组成与结构联合设计，从零构建协作图。
- 依查询顺序：决定 agent 数 → 从可扩展角色池选角色 → 建最优通信链。
- 生成式而非模板修改，拓扑量身定制、灵活可扩展。

## 关键贡献
- 提出自回归图生成范式，突破模板修改范式的冗余与僵化。
- SOTA 性能 + 更高 token 效率 + 可扩展角色池。

## 实验与数据
- 六多样基准 SOTA；token 效率显著提升；可扩展性增强。

## 局限与不足
- 自回归生成需训练；生成顺序与角色池设计影响质量；长程任务与端边云未涉及。
