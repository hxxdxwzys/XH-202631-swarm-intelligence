# QLMIO: Multimodal LLM Offloading in Cloud-Edge Continuum

> [!info] 元信息
> - **ArXiv**: `2606.15210`
> - **作者 / 年份**: Zhongxiao Wang et al. (西电/浙大/西交/UNSW) / 2026
> - **主题分类**: [[inference-serving]]
> - **本地文本**: [2606.15210.txt](file:///../_pdf_text/2606.15210.txt)

## 一句话总结
针对云-边连续体中多模态 LLM 推理卸载，提出 QLMIO 框架联合优化生成质量与响应延迟：含推理延迟预测(MILP)与生成质量预测(MGQP)两能力，主动预测以最优平衡二者，延迟最高降 58.14% 且任务完成率匹敌纯云。

## 问题与动机
云-边连续体部署异构参数规模 MLLM（云可部署 30B、边仅 2B），用户同时关心多 QoS 属性，联合优化困难；预测 MLLM 推理延迟与生成质量本身极难。

## 核心方法
- **QLMIO 框架**：① MLLM 推理延迟预测(MILP)；② MLLM 生成质量预测(MGQP)，主动预测延迟与生成正确概率以平衡质量-延迟。
- 构建真实云-边协同 MLLM 系统，采 MIOBench 基准。
- 异构设备/模型：云 RTX5090(32GB) 跑 30B Qwen3-VL，边 Jetson(8GB) 跑 2B。

## 关键贡献
- 首个面向多模态 LLM 云-边卸载的质量-延迟联合优化框架。
- 提供延迟与质量预测两能力 + 真实基准 MIOBench。

## 实验与数据
- 延迟最高降 58.14%，任务完成率匹敌纯云全量执行。

## 局限与不足
- 面向推理卸载，非 agent 任务级调度；预测模型需训练；多 agent 协作未涉及。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
QLMIO 是赛题"端-边-云异构资源自适应调度"的直接工业参照：云-边异构模型按质量-延迟预测动态卸载——正中赛题"依据子任务实时性与数据敏感等级自动完成推理位置动态选择与模型切分"。其质量-延迟预测可纳入执行引擎(#4)调度钩子。与 [[2405.14371 EdgeShard]]、[[2311.18677 Splitwise]] 共同构成端边云调度文献簇，且补足多模态维度。
