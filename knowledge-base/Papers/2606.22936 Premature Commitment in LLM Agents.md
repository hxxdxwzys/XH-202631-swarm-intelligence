# Premature Commitment in LLM Agents

> [!info] 元信息
> - **ArXiv**: `2606.22936`
> - **作者 / 年份**: Aman Mehta (Snowflake AI Research) / 2026
> - **主题分类**: [[safety-robustness]]
> - **本地文本**: [2606.22936.txt](file:///../_pdf_text/2606.22936.txt)

## 一句话总结
诊断长程 agent 的"过早承诺"失败模式：agent 早早就锁定一种证据解读、后续全程为之辩护；定义跨运行隐状态收敛为表征承诺信号，step-4 隐状态相似度可预测下游轨迹一致性，运行时监测 AUROC 达 0.97，prompt 干预降方差 28%。

## 问题与动机
长程 agent 会"悄悄失败"：早早锁定一种解读后全程辩护，轨迹看似连贯实则围绕首个解读（对错不论）闭合。终答案评分看不见此失败，跨运行一致性也 ambiguous（错也可能自洽）。

## 核心方法
- **表征承诺(representational commitment)**：固定推理步的跨运行隐状态收敛（同输入多次采样，取步 s 最后 token 隐状态的成对余弦相似度）。
- 高相似度=已锁定稳定解读；低=仍依赖证据路径。
- 运行时监测读 step-4 隐状态标记不一致轨迹；prompt 干预提升收敛、降方差。

## 关键贡献
- 提出"过早承诺"这一隐蔽失败模式与隐状态诊断信号。
- 证明承诺是过程一致性维度而非正确性维度（committed-wrong 与 committed-correct 不可分）。

## 实验与数据
- Llama-3.1-70B ReAct HotpotQA：step-4 相似度预测一致性 r=-0.35(部分-0.45)；跨 Qwen/Phi 复现，StrategyQA r=-0.83；监测 AUROC 0.97(分位)/0.85-0.88(中位)；prompt 干预降方差 28%。

## 局限与不足
- 诊断而非通用提准确率手段；自洽计算路由收益有限；单层 activation steering 混合。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
本文揭示赛题"规划幻觉""过程遗忘"的一个隐蔽根因——agent 过早锁定解读。其隐状态监测可作赛题运行时鲁棒性监控的参考：在长链中检测"已僵化"轨迹并触发重规划/多路径。与 [[2606.22953 Plans Dont Persist]] 同属"长程 agent 隐性失效"诊断，对赛题鲁棒容错与可观测有强启发。
