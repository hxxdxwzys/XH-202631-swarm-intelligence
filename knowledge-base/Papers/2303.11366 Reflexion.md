# Reflexion: Language Agents with Verbal Reinforcement Learning

> [!info] 元信息
> - **ArXiv**: `2303.11366`
> - **作者 / 年份**: Noah Shinn et al. (Northeastern/Princeton/MIT) / 2023
> - **主题分类**: [[tool-use]]
> - **本地文本**: [2303.11366.txt](file:///../_pdf_text/2303.11366.txt)

## 一句话总结
不更新权重，而是让 agent 把环境反馈转写成"语言反思"，存入情景记忆缓冲，在后续试验中据此改进决策——一种"语言强化学习"。

## 问题与动机
传统 RL 让 agent 从试错中学习需大量样本与昂贵微调，对大模型 agent 不现实。希望找到轻量、无需梯度更新的自我改进途径。

## 核心方法
- **Reflexion**：把标量/二元环境反馈转化为自然语言反思摘要（语义梯度），作为额外上下文加入下一轮试验。
- 维护**情景记忆缓冲**存储反思文本。
- 反馈来源可灵活：环境二值反馈、预定义失败启发式、自我评估（LLM 自判/自写单元测试）。

## 关键贡献
- 提出"verbal RL"范式：用语言反思替代权重更新，轻量、可解释、无需微调。
- 把记忆显式化为可读的经验摘要，便于调试与信用分配。

## 实验与数据
- HumanEval 编程 pass@1 达 91%，超 GPT-4 的 80%。
- ALFWorld 决策 +22%（12 轮迭代）；HotPotQA 推理 +20%；HumanEval 编程 +11%。

## 局限与不足
- 依赖 LLM 自评能力，无成功保证；反思可能强化错误归因；记忆缓冲会膨胀需管理；试验次数受上下文预算限制。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
Reflexion 几乎是为赛题鲁棒容错支柱量身定做：失败→语言反思→情景记忆→下次改进，正是"自主纠错"。其反思摘要是一种天然低熵信息（只留可操作教训）。执行引擎(#4)的 L1 语义失败重试可直接采用 Reflexion 机制：失败时生成结构化反思存入记忆，再重试或上报。
