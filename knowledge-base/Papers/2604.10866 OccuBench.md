# OccuBench: Cross-Industry Professional Task Benchmark

> [!info] 元信息
> - **ArXiv**: `2604.10866`
> - **作者 / 年份**: Xiaomeng Hu et al. (Qwen Team/阿里巴巴/CUHK) / 2026
> - **主题分类**: [[benchmark]]
> - **本地文本**: [2604.10866.txt](file:///../_pdf_text/2604.10866.txt)

## 一句话总结
用 LLM 驱动的语言环境模拟器(LES)覆盖 100 个真实职业任务（10 行业/65 专业域），多 agent 合成管线自动产出可解、难度校准、文档支撑的评测实例，并做受控故障注入（显式错误/隐式数据退化/混合）评测鲁棒性。

## 问题与动机
agent 最有价值的职业域（医疗/金融/能源/海关…）恰是无公开环境、不可逆的"不可测多数"；既有基准只覆盖有环境的少数域，扩展成本高，且只测 happy path、不评鲁棒性。

## 核心方法
- **语言环境模拟器(LES)**：LLM 作有状态交互环境模拟器，把环境构建从工程问题变为配置问题——任何 LLM 能理解的域都可评测。
- 100 场景/10 行业/65 域/382 实例；多 agent 合成管线保证可解、难度校准、文档支撑。
- 双维评测：跨域任务完成 + 受控故障注入下的环境鲁棒性（显式/隐式/混合）。

## 关键贡献
- 首个系统化跨行业职业任务评测，用 LES 突破环境覆盖瓶颈。
- 显式引入故障注入评测鲁棒性——罕见且贴合赛题。

## 实验与数据
- 15 前沿模型/8 家族：无单一模型通吃；隐式故障最难（无显式信号需自检）；推理努力提升显著（GPT-5.2 +27.5）；强 agent 未必是强模拟器。

## 局限与不足
- LES 依赖模拟器质量；模拟 vs 真实差距；单 agent 评测，未涉及多智能体动态拓扑。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
OccuBench 几乎逐项命中赛题：跨行业职业任务（"数字劳动力"应用契合度）、故障注入评测鲁棒性（"接受异常注入"）、LES 思想可作赛题评测环境构建方法。其"隐式故障最难"结论直接支撑赛题鲁棒容错设计。是赛题评测体系(#5)与场景(#6)的旗舰参照。
