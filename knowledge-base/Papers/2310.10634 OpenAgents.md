# OpenAgents: Open Platform for Language Agents

> [!info] 元信息
> - **ArXiv**: `2310.10634`
> - **作者 / 年份**: Tianbao Xie et al. (HKU XLang/Sea AI/Salesforce) / 2023
> - **主题分类**: [[agent-framework]]
> - **本地文本**: [2310.10634.txt](file:///../_pdf_text/2310.10634.txt)

## 一句话总结
面向真实日常使用的开源 agent 平台，含三类 agent：Data Agent（Python/SQL 数据分析）、Plugins Agent（200+ 日常 API）、Web Agent（自主浏览），并提供面向普通用户的 Web UI 与本地部署。

## 问题与动机
既有 agent 框架多为概念验证、面向开发者控制台，忽视非专家用户访问与应用级设计；商业方案不开源，阻碍研究。

## 核心方法
- 三类 agent：Data Agent（数据分析+工具）、Plugins Agent（200+ API）、Web Agent（浏览/聊天两种）。
- 面向用户的 Web UI：优化快速响应与常见错误处理。
- 面向开发者的本地部署：前后端完整代码。
- 面向研究者的共享组件与示例。

## 关键贡献
- 提供端到端、面向真实用户的开源 agent 平台，降低使用与部署门槛。
- 覆盖数据分析、工具调用、Web 浏览三类高频真实场景。

## 实验与数据
偏系统/平台贡献；展示三类 agent 在真实任务的能力与挑战，附 Web UI 体验。

## 局限与不足
- 单 agent 为主；无动态拓扑/低熵通信；长程与多 agent 协作未深入；偏工程平台而非算法创新。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
OpenAgents 是赛题"可运行系统"与"前端展示"(#7)的工程参照：面向用户的 Web UI、错误处理、本地部署、三类真实场景。其 Data/Web Agent 场景可映射赛题"跨域多模态投研"演示。但需在其单体平台上叠加多智能体动态拓扑与记忆容错。
