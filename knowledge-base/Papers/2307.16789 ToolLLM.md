# ToolLLM: Mastering 16000+ Real-World APIs

> [!info] 元信息
> - **ArXiv**: `2307.16789`
> - **作者 / 年份**: Yujia Qin et al. (清华/ModelBest/RUC/Yale/Tencent) / 2023
> - **主题分类**: [[tool-use]]
> - **本地文本**: [2307.16789.txt](file:///../_pdf_text/2307.16789.txt)

## 一句话总结
构建覆盖 16464 个真实 RESTful API 的 ToolBench 指令数据集，微调出 ToolLLaMA 并配神经 API 检索器，用 DFS 决策树搜索多轮 API 调用路径，使开源模型工具使用能力逼近 ChatGPT。

## 问题与动机
开源 LLM 经指令调优后仍弱于闭源模型在工具使用上的能力，且既有工作 API 数量少、范围窄、多限单工具，无法应对真实多工具交织的复杂任务。

## 核心方法
三阶段构造 ToolBench：① 收集 RapidAPI 16464 个 API（49 类）；② ChatGPT 生成单/多工具指令；③ ChatGPT 搜索有效 API 调用链作解。
- **DFSDT**：深度优先搜索决策树算法，让 LLM 评估多条推理轨迹、扩展搜索空间。
- **ToolEval**：自动评测工具使用能力。
- 微调 LLaMA 得 ToolLLaMA + 神经 API 检索器推荐 API。

## 关键贡献
- 首个面向海量真实 API 的工具学习数据/模型/评测闭环。
- DFSDT 把搜索引入工具调用决策，提升多轮 API 规划能力。

## 实验与数据
- ToolLLaMA 在复杂指令执行与未见 API 泛化上可比 ChatGPT；在 APIBench 上具 zero-shot 泛化。

## 局限与不足
- 依赖 ChatGPT 生成数据（质量上限）；RESTful API 副作用/鉴权未充分建模；端到端真实任务成功率受限于环境；无多 agent 协作。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
ToolLLM 的"API 检索器 + DFSDT 多轮调用搜索"是赛题执行引擎(#4 工具调用)的关键参考：在巨大动态工具空间中先检索再调用、用搜索应对多步工具规划。DFSDT 的回溯机制也服务鲁棒容错。其数据构造方法可借鉴用于构建赛题高质量多智能体数据集（打分项 b：数据集构建）。
