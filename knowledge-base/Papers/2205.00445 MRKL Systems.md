# MRKL Systems (Modular Reasoning, Knowledge and Language)

> [!info] 元信息
> - **ArXiv**: `2205.00445`
> - **作者 / 年份**: Ehud Karpas et al. (AI21 Labs) / 2022
> - **主题分类**: [[tool-use]]
> - **本地文本**: [2205.00445.txt](file:///../_pdf_text/2205.00445.txt)

## 一句话总结
提出一种神经-符号模块化架构：用路由器把自然语言请求分发到 LLM 与各类"专家"模块（计算器、知识库、检索等），以弥补 LLM 在时效信息、专有数据、精确推理上的固有缺陷。

## 问题与动机
LLM 存在三类核心局限：① 无法获取动态/时效信息；② 无法访问专有数据源；③ 神经网络不擅长精确计算与符号推理。且为每个任务微调大模型会导致"模型爆炸"与灾难性遗忘。

## 核心方法
- **MRKL 架构**：由可扩展的"专家(experts)"模块集合 + 一个**路由器(router)**组成，路由器把每条自然语言输入送到合适的模块。
- 专家既可是神经模型，也可是离散推理/知识模块（如计算器、日历、SQL、检索器）。
- 实现 **Jurassic-X**：AI21 的 MRKL 落地系统。

## 关键贡献
- 早期系统化提出"LLM + 外部工具/知识模块 + 路由"的神经-符号范式，是 tool-use / agent 路由思想的先驱之一。
- 明确将"路由"作为一等公民——与赛题"动态拓扑路由"高度同构。

## 实验与数据
无显著定量结果（偏架构/立场论文），以示例说明 GPT-3/Jurassic-1 在算术、时效事实上的错误及 MRKL 如何修正。

## 局限与不足
- 路由器如何训练、多模块协作如何编排未深入；偏概念性，缺乏端到端长程任务验证。

## 与赛题关联
> 赛题四大支柱：长程记忆 / 动态拓扑低熵通信 / 端边云调度 / 鲁棒容错。
MRKL 的"路由器+异构专家"正是赛题"动态异构拓扑"的雏形：把请求按语义路由到不同能力模块，避免全连接冗余。其神经-符号分工思想也契合赛题"神经符号协同推理"。可借鉴其模块化专家设计，但需把静态路由升级为动态稀疏图路由。
